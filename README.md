# ICTEdu

ICT Edu〜AI時代の学力をシステム開発で支援する〜 のドキュメント・成果物を管理するリポジトリです。

- 正本：このリポジトリ（GitHub）
- 閲覧用：Notion（GitHub → Notion の一方向で同期予定）

## 構成

```
CHANGELOG.md          サービスの継続・中止・改名・方針変更の履歴（変更管理）
docs/
  minutes/            議事録（YYYY-MM-DD_名前.md、一覧は README.md）
  services/           サービスごとの概要（ブレインナイト・ファクター・れこでぃ・ModeOS）
  project/
    overview.md       目的・KGI・サービス一覧
    schedule.md       イベント・タスクの進行状況
    members.md        担当者・役職・作業チェック
    notion-structure.md  Notion のDB構成と GitHub との対応（構成管理）
```

議事録のコミット日は、会議の日付に合わせています（`git log` がそのまま時系列になります）。
