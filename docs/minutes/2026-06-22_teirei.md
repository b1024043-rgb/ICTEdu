# 定例議事録（2026-06-22）

## アジェンダ

## 議論
- 小学生向けのアプリ
- 伊藤先生「桔梗小学校側にメリットを意識して」
- 現状の桔梗小
  - 2030年に教科書変わるから、マニュアル作り直す手間
  - タイピングは2年生でやる
  - デジタル化により生徒の睡眠時間が減少（エンタメが増えたから）
  - 授業中のサボり → 後ろから教師が監視する
  - デジタル化によりモチベ↑、成績変化なし（多分）
  - 教師だとマニュアル作りが最も手間かな？
- ケータイプロジェクトにとると
  - 小学生：Youtubeばっかで歯磨きとかやらない子とかいる
  - 習慣づけ：歯磨き、片付け、読書とかを支援する
  - 66日で習慣化
- スマホの使用時間を減らすのは難しそう
- 学力上げる？習慣改善する？
  - 睡眠の改善が学力向上につながる
  - スマホで勉強をできるようにする
  - 習慣よくしたら、学力も上がる（睡眠とか）
- 桔梗小を説得させる資料を用意してメリットを伝えたい
- 親の協力が必要になるかも？ → ただ、親に監視されるのは子供にとって負担
  - 先生に管理させるのもあり？
  - 宿題はすでにデジタル化している（紙でもやっている）
- 授業中にサボる人増えてるでしょ
- 家で勉強する時間を増やすのがやりやすいかも
- 勉強特化習慣（親に依存）
- 小学生が主体は危険かな？監視がする

### 「習慣アプリを一旦考える」
- どんな小学生をターゲット
  - 睡眠時間が少ない人
  - 検索したものをAIコピペする人
  - 字汚い子供
  - 宿題ださない子供
  - 高学年
- 小学生向けのAIを作成？
- 習慣づけは低学年からがいい
- 睡眠改善アプリ：睡眠前にした勉強を記録して、睡眠中に放置ゲーが進んでいく
- 高学年は中学生の準備が必要
- 音読アプリ：パソコンに話しかける
