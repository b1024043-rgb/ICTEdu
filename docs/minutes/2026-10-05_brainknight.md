# 定例議事録（ブレインナイト部門）（2026-10-05）

## 議題
1. ブレインナイトを作成する背景・目的・期待する効果の決定とメンバー間の認識揃え（25分）
2. 前項を踏まえて現在の生活フローを2人1組のペアで考えてみる作業＋発表して1つに決定（作業15〜25分＋発表5分＋決定時間15分）
3. ブレインナイトを取り入れるべき箇所の決定と取り入れた後のフローの作成（30分）
4. ブレインナイトで必要な機能（MVP）の決定（30分）とその詳細仕様の決定（残りの時間分）

ゴール
- [ ] MVPが決定しメンバー間で一致する
- [ ] MVPを実現するための仕組みが決まる

対象：小学生（5・6年）

- 健康になってほしい

## 要件定義
生徒と保護者は、それぞれ何を記録するイメージですか？
- 生徒：睡眠時間／今期の目標／勉強時間の記録／勉強科目
- 保護者：生徒の記録に対するコメント

「楽しい」と感じる仕掛けとして、どれが近いですか？（複数可）
- キャラクターを育てる
- 勉強記録の連続記録を表示

記録項目（まとめ）：睡眠時間／保護者のコメント／勉強時間／生徒の目標

検討した問い
- 保護者はどうやってログインしますか？
- 「適切な睡眠時間」の目標は誰が決めますか？

### 概要
小学5・6年生の睡眠習慣づくりを主役に、学習習慣も支えるWebアプリ。学年単位で導入し、生徒と保護者が記録し、先生が見守る。

### 利用者と役割
- 生徒（学校配布のChromebook）：寝る前・起きた後にボタンで睡眠を記録、勉強時間と科目を記録、学期ごとに目標を自由記述
- 保護者（自分のスマホ）：生徒アカウントでログイン後、PINで保護者モードに切り替え、生徒の記録にコメント
- 先生：睡眠時間・勉強時間・目標・保護者コメントを閲覧し、生徒にコメントを送れる

### 主な機能（初版）
- 睡眠記録：就寝・起床のワンタップ記録。押し忘れは後から手入力で修正でき、修正した記録には印がつく
- 睡眠目標：小学生の推奨睡眠時間（9〜12時間）を一律に適用
- 勉強記録：時間と科目。連続記録日数を表示
- キャラクター育成：睡眠目標の達成と勉強記録の両方で成長。未達成や記録忘れのときは成長が止まるだけで、後退や罰はない
- 学期目標：学期ごとに生徒が自由記述

### 決める前に確認しておきたいリスク
1. 生徒アカウントを保護者のスマホで使えるか。学校のGoogle Workspaceは、管理外の端末からのログインを禁止していることがよくあります。学校のIT担当に確認が必要です。また、PINを子どもが知ってしまうと保護者コメントのなりすましが起こりえます。
2. 寝る前にChromebookを開くこと自体が、睡眠に悪影響を与えうる点。就寝記録は開いてすぐ押せる最小の操作にし、画面を暗くするなどの配慮が必要です。夜間に端末の利用を制限している学校もあります。
3. 個人データの扱い。先生が個人の睡眠記録を見るため、保護者の同意の取り方、データの保存期間、学年が変わったときの引き継ぎを決める必要があります。

### まだ決まっていない点
- 「目標達成」の判定基準（例：9時間以上なら達成）
- 先生のコメントは生徒と保護者のどちらに見えるか
- 寝る時間のリマインド通知は必要か（ChromebookのWebアプリでは通知に制約があります）
- 6年生の卒業時にキャラクターやデータをどうするか
