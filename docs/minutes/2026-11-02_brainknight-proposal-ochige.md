# アプリ企画概要：睡眠習慣改善アプリ
仮称・ゲーム要素を取り入れた生活習慣改善アプリ

## 1. アプリの目的・コンセプト
小学生を対象に、ゲームの仕組みを利用して、睡眠習慣や日常生活の習慣を改善することを目的としたアプリ。
単にゲームを楽しむのではなく、キャラクターの成長を通して、子どもが自発的に規則正しい生活を送れるようにする。

コンセプト：自分の生活と一緒に、キャラクターも成長していく。

## 2. 想定する利用者・利用環境
- 対象：小学生（主に中・高学年を想定）
- 利用環境：Chromebook
- 形式：Webアプリを想定
- 学校でも家庭でも利用できることを目指す。

## 3. キャラクターシステム
（参考画像：Cozy Forest、Astrapuffs、Blingvalley — Notion上）

アプリの中心となるのは、ユーザー自身の分身となるキャラクター。
- 人型またはマスコット型から好きなタイプを選べる。
- ユーザーが勉強するとキャラクターも勉強する。
- ユーザーが歯磨きをするとキャラクターも歯磨きをする。
- ユーザーの睡眠や日常生活の積み重ねによってキャラクターが成長する。
- キャラクターは自分の分身であると同時に、一緒に生活するパートナーでもある。

キャラクターを育てるというより、自分自身の生活をキャラクターに反映させるという考え方を重視する。

## 4. 睡眠管理システム
アプリの最も重要な機能。
- 年齢や起床したい時間などに合わせて、個人ごとの睡眠目標を設定する。
- 就寝時刻と起床時刻を記録する。
- 実際の睡眠時間を計算する。
- 目標睡眠時間を達成できたか判定する。
- 就寝・起床時刻の規則正しさも別に評価する。
- 1週間の睡眠記録を確認できるようにする。

睡眠時間と生活リズムを分けて評価することで、十分な睡眠を確保することと、規則正しい生活を送ることの両方を目指す。

## 5. 日常生活の記録機能
睡眠以外にも、日常生活の良い行動を記録できるようにする。
記録する行動の例：宿題・勉強／歯磨き／お手伝い／運動／その他の良い生活習慣

記録方法は2種類。
1. 行動した直後に、その場で記録する。
2. 夜に1日の行動を振り返り、記録の追加や修正をする。

記録した行動に合わせてキャラクターも同じ行動をする。

## 6. キャラクターの成長システム
睡眠や日常生活の行動によって経験値を獲得し、一定の経験値に達するとレベルアップする。

| 行動 | 獲得経験値 |
| --- | --- |
| 目標睡眠時間を達成 | 70 XP |
| 目標就寝時刻を守る | 15 XP |
| 目標起床時刻を守る | 15 XP |
| 宿題・勉強 | 2 XP |
| 歯磨き | 1 XP |
| お手伝い | 2 XP |
| 運動 | 2 XP |

レベルアップのルール
- 100 XP獲得すると1レベル上がる。
- 次のレベルに必要な経験値は常に100 XP。
- 経験値は翌日以降に持ち越す。
- レベルが下がることはない。
- 睡眠に関する行動を、その他の日常生活の行動よりも高く評価する。

## 7. ゲームシステムの設計方針
- 睡眠習慣の改善を最優先にする。
- 睡眠以外の行動は追加的な評価とする。
- 毎日の積み重ねがキャラクターの成長に反映される。
- レベルが上がりにくくなっていく仕組みにはしない。
- できなかったことに対するペナルティを設けない。
- 他の子どもとの過度な競争や比較を促さない。

特に、日常的に行ってほしい歯磨きなどに大きな報酬を設定しないことで、報酬のインフレやモチベーションの低下を防ぐ。

まずは睡眠管理とキャラクターの成長を中心としたアプリを完成させる。
