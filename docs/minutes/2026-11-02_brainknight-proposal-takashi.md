# ブレイン・ナイト企画概要

## 1. コア・コンセプト
「夜の睡眠」と「昼の学習」が、自分のキャラを育てる
- 昼（準備）：勉強を記録し、連続ボーナスを獲得
- 夜（就寝）：画面直撃を防ぐ1タップ就寝・暗転UI・夜の環境音で入眠をサポート
- 朝（成果）：起床（または翌朝確定）で夜明けが訪れ、睡眠時間に応じキャラが成長

## 2. 運用・設計のポイント（落としどころ）
| 項目 | 懸念点 | 解決策（落としどころ） |
| --- | --- | --- |
| 睡眠改善 | 端末の夜間ロック／持ち帰り制限 | 「夜の1タップ」と「翌朝の手入力補正」のダブル運用 |
| 習慣化 | 目標9時間のハードル／挫折 | 個人別の目標設定（7〜9時間）＋ 未達成でもペナルティなし |
| 保護者 | 「監視」による摩擦 | 詳細な数値ではなくスタンプや頑張りメーターなどポジティブ指標を優先 |
| 先生 | コメント対応によるオーバーワーク | 個別返信は不要。ワンタップスタンプ ＋ クラス全体の共同イベント化 |
