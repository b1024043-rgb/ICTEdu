# Notion ワークスペースの構成

```
ICT Edu〜AI時代の学力をシステム開発で支援する〜（Wiki DB）
└─ トップページ（クイックボタン／目的とKGI／サービス一覧）
   ├─ ルール・役職
   │  ├─ このICT演習チームの役割未定・消すつもり
   │  └─ この演習チームの役割
   └─ DB
      ├─ 議事録DB            … 議事録は意思決定ログ（テンプレート：定例議事録／議事録β）
      ├─ イベント進行状況     … 工程・行事。タスクを束ね、EV/PV・進捗率を集計
      ├─ タスク進行状況       … 見積もり工数・担当者・開始終了日
      ├─ サービスポートフォリオ … サービスごとのパイプライン段階・公開先・責任者
      ├─ 担当者              … 役職・担当タスク・個人進捗率
      └─ 作業チェック         … タスクの作業を1項目ずつ管理
```

## DB間の関係
- 議事録DB.サービス → サービスポートフォリオ
- イベント進行状況.サービス → サービスポートフォリオ
- イベント進行状況.タスク ⇔ タスク進行状況.所属イベント
- タスク進行状況.担当者 ⇔ 担当者.担当タスク
- サービスポートフォリオ.マイルストーン = 関連イベントの最新日付（ロールアップ）

## サービスポートフォリオのパイプライン段階
企画 → 要件定義 → 基本設計 → 詳細設計 → 実装 → 単体テスト → 結合テスト → Appstore公開中
