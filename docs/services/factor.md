# ファクター

> 注意：以下はNotionのサービスページ（最終更新 2026-10-13）の内容です。2026-11-02の会議で「小野案（大学生向け・授業知識と興味をつなぐ学習支援）で作成する」と決定しており、このページの内容とは方向が異なります。詳細は [小野案・要件定義](../minutes/2026-11-02_factor-ono-requirements.md)。

## プロジェクトの背景
GIGAスクールや生成AIの普及により、小学生がネット上の情報をそのまま鵜呑みにしてしまうケースが増加しています。
学校現場では、授業時間を削らずに子どもたちの「情報を鵜呑みにしない思考力」を日常的に育てる方法が求められています。

## 機能
- 2段階の回答システム：カードのスワイプ判定後に、回答結果へ応じて変化する根拠（理由）を選ばせ、思考プロセスを可視化します。
- 10秒でできる問題作成：教科書の文章から1単語を入れ替えるだけで罠問題が作れ、解説文はAIが安全に自動生成します。

## 期待する効果
朝の1分間という手軽な習慣を通して、情報に接したときに一歩立ち止まって根拠を確かめるファクトチェック思考が身につきます。
自分自身で問題（罠）を作る体験により、情報の作り手側の意図やトリックを見破る視点が育ちます。
