# れこでぃ

- 簡単に記録することに特化した。
- ウィジェットでも通知先でも記録
- アプリを開かなくても記録
- 過去のランク記録は編集不可
- メモはいつでも編集可
- 4つまでのランク、自己申告性

## 小学校に伝えること

### 背景
小学生は自己管理が苦手で主体的な行動が難しい
例：なんとなくYoutubeやTiktokを見てたら、1日がすぐ終わってしまった
その人向けに簡単に勉強などの記録ができるアプリで自己管理をする。

### 機能
- 日々の生産的な行動をランクで記録（勉強、ピアノ、サッカー等）
- スマホのウィジェットから記録が見れる
- 毎日設定した時間に通知が飛んで、通知から記録が可能（アプリを開かなくても簡単に記録）
- 月ごとの記録をグラフで見れる
- クラスメイトの記録がグラフで見れる（匿名）

### 期待する効果
- クラスメイトの記録から、相対的に自分の位置付けを自覚
- 自分を振り返って、惰性の日々を自覚し行動的なモチベーションを上げる
